## 页面结构

| 文件 | 内容 |
| --- | --- |
| `index.html` | 首页：姓名、简介、真实照片、模块导航 |
| `education.html` | 教育背景（硕士/本科）+ 荣誉奖项 |

## 怎么改内容

- 直接编辑对应 HTML 文件里的文字即可，所有页面样式共用 `css/style.css`。
- 照片在 `assets/photo.png`（从你的简历 PDF 中提取），想换照片直接覆盖这个文件（建议正方形，如 400×400 以上）。
- 顶部导航的「来聊聊」按钮指向邮箱 `320589552@qq.com`，电话在首页联系区：`15317270326`。
- 配色在 `css/style.css` 顶部的 `:root` 变量里，改一处即可全局换色。
